# 🚀 Day 1: Welcome to OpenShift Administration! 

Welcome to the first day of our OpenShift Administration workshop! 🎉
Today, we are going to get our hands dirty and start exploring the cluster. 

*Note: Remember that our cluster is operating in an air-gapped environment (no internet access). All the resources you need are already available inside!*

## 🎯 Today's Goals
- Get familiar with the OpenShift CLI (`oc`).
- Understand basic cluster exploration.
- Deploy your very first internal application.

---

## 🛠️ Prerequisites
Before we begin, let's make sure your environment is ready to go.
- [ ] You have terminal access.
- [ ] You have your cluster credentials ready.

---

## 🏋️‍♂️ Exercise 1: Logging In and Looking Around
Let's make sure we can talk to our cluster and see what it's made of.

### 📝 Task
1. Log in to your cluster using the `oc` command.
2. Check the cluster nodes status.

### 💻 Commands
```bash
# Log in to the cluster (replace with your actual credentials)
oc login -u <username> -p <password> <api-url>

# Check the nodes in the cluster
oc get nodes
```

### ✅ Verification
You should see a list of nodes with the status `Ready`.

---

## 🏋️‍♂️ Exercise 2: Creating Your First Project
Now that we are in, let's create a dedicated space for our work.

### 📝 Task
1. Create a new project named `day1-workshop`.
2. Verify you are currently in the new project.

### 💻 Commands
```bash
# Create a new project
oc new-project day1-workshop

# Check your current project
oc project
```

### ✅ Verification
The output should confirm that you are currently on project `day1-workshop`.
